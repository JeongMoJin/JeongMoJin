## I build, measure, and remember.

안녕하세요. 저는 **기록하는 크리에이티브 테크 빌더, Jeong Mo Jin**입니다.

공공데이터와 AI로 문제를 읽고, TypeScript와 Python으로 빠르게 제품화하며, Unity와 영상 도구로 사람이 느낄 수 있는 경험까지 만듭니다. 제 GitHub는 완성품만 진열하는 곳이 아니라, 배운 것과 만든 것과 다시 개선한 흔적을 함께 남기는 작업실입니다.

```txt
public data       -> insight
insight           -> product
product           -> experience
experience        -> record
record            -> next build
```
